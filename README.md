# Markdown Viewer

A fast, private, GitHub-style Markdown editor and live previewer. Documents stay
in the browser and are automatically saved to local storage.

[Open the free Markdown viewer](https://mdf-viewer.vercel.app/) ·
[Read the Markdown guides](https://mdf-viewer.vercel.app/guides)

## Features

- Sanitized GFM rendering with raw HTML support
- Syntax highlighting, Mermaid diagrams, KaTeX math, alerts, emoji, and footnotes
- Drag-and-drop upload plus Markdown, HTML, PDF, clipboard, and print exports
- Resizable desktop workspace and mobile editor/preview tabs
- Persistent light/dark theme, search, reading stats, and fullscreen preview

## Development

```bash
npm install
npm run dev
```

Run `npm run build` for a production build.
